Automatic features
How capture works

Browser downloads are handed to Syphon. The browser transfer is cancelled only after the app accepts the request.

Privacy and limits

Shares matching site cookies, the referring page and browser identity with Syphon. Sign-in data stays in memory until Syphon closes; send the link again after reopening. Not available for YouTube, media tools, private browsing or partitioned cookies.

Permissions and supported media

Supports YouTube and unprotected HLS/DASH. Requires permission to observe requests on HTTP/HTTPS pages. Protected playback cannot be extracted.

What happened?

Desktop connection

Connection is based on the last handoff reply. Refresh status to contact Syphon again.

Connect or reconnect the app

Run connect-browser.ps1 in the Syphon folder, then reopen this menu. This registers the per-user native host for Chrome and Edge.
