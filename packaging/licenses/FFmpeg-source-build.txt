Syphon FFmpeg/FFprobe 9.0.2 source build (Windows x64)

This package contains the Syphon native source build, not the older Gyan full
build. GPL and version-3 licensing are enabled; nonfree is disabled. External
libraries: zlib 1.3.2, libxml2 2.15.4, libwebp 1.6.0, LAME 3.100 and pinned x264
b35605ace3ddf7c1a5d67a2eb553f034aef41d55. Windows Schannel supplies TLS.

Exact upstream notices are retained in licenses/ffmpeg-source-build. The
FFmpeg GPLv3 text, build/input record, compatibility record, source archive
identity and independent engineering review are included in licenses.
