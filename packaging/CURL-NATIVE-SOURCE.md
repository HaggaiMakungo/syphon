# curl_cffi and libcurl native source mapping

The pinned curl_cffi 0.16.0 Windows x64 wheel contains a libcurl DLL with SHA-256 `ec8ead0e422fe4ae62a99233a63f6007adc727caba97ff1f87385c00cafe200f`. It is **byte-for-byte identical** to `lib/libcurl-impersonate.dll` from the [upstream v2.0.0 Windows x64 asset](https://github.com/lexiforest/curl-impersonate/releases/tag/v2.0.0). The asset's SHA-256 matches GitHub's retained release digest; the wheel is independently pinned by the build lock and matching PyPI metadata. Its renamed DLL filename does not conceal a different library.

The wrapper's full source at commit `965508e0cd777369bd2f825162da6dbde9140f4e` and source release are retained. `scripts/build.py` selects exactly this upstream v2.0.0 x86_64-win32 dynamic library. Native source is pinned to tag commit `ec41b71ce888806bfec56ada7a7258d333eb3d19`. Its [CMake recipe](https://github.com/lexiforest/curl-impersonate/blob/ec41b71ce888806bfec56ada7a7258d333eb3d19/CMakeLists.txt) includes explicit SHA-256 values for all eight source inputs: curl 8.21.0, BoringSSL commit156c7b75ae9b8c3b3f847acf264f17594c3859fb, Brotli1.2.0, nghttp2 1.63.0, nghttp3 1.15.0, ngtcp2 1.20.0, zlib1.3.1 and zstd1.5.7. All eight retained archives match those hashes. Their previously historical filenames do not substitute for this current explicit verification.

The complete source archive retains every project patch, CMake helper and Windows build script. The Windows workflow selects windows-2022 and calls `win/build.bat vcvars64`: VS2022 environment, Ninja, clang-cl C/C++, Microsoft link.exe, Release, static CRT and libidn2 disabled. It builds and installs the native library and packages lib/include. Exact flags and member hashes are recorded in curl-native-source-review.win-x64.json. The disabled libidn2 is not invented as a linked Windows dependency.

All native source license texts are retained. Seven of nine root license texts match the installer aggregate after whitespace normalization; the curl and zlib copyright-year text differs, so their exact notices are also provided as a supplemental companion. The original aggregate is preserved. Source material/recipe mapping is complete for this identified native chain. This is not an independent build, a bit-identical reproduction claim or legal certification; precise original runner/compiler package versions are not supplied.
