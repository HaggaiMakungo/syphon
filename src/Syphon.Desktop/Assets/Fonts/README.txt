Native dialog fonts

Inter-Regular.ttf and Inter-SemiBold.ttf are lossless SFNT conversions of the
existing @fontsource/inter 5.2.8 Latin 400/600 normal WOFF assets in
ui/charts/node_modules/@fontsource/inter/files. Font outlines were not changed.
Converted with fontTools 4.67.0 (TTFont, flavor=None).

Inter is licensed under SIL Open Font License 1.1. The existing Inter notice
is included in DesktopAssets/THIRD-PARTY-NOTICES.txt and installed license notices.
These resources let native dialogs use the same Inter body text as the HTML UI.
