# Violet Studio layout explorations

The first four layout explorations were superseded by the user's instruction that windows should not be very wide. The compact variants are the current direction.

- Command Deck: top navigation and full-width stacked rows.
- Focus Fold: selected row expands vertically, avoiding a permanent side inspector.
- Transfer Shelves: vertically grouped active, queued and paused transfers.
- Mini Studio: selected-transfer overview above a compact queue.

Preserve graphite surfaces, violet actions, lavender progress and comfortable text. Target main-window proportions near 850 × 700 in the presentation, with separate narrow companion windows. These are illustrative static images, not implemented application changes or actual sizing tests. Generated using the built-in image generation tool with 01-violet-studio.png as reference.
