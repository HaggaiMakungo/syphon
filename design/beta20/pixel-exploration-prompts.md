# Pixel-inspired main-window concepts

Four static layout concepts generated with the built-in image generation tool using the user's UI Experiment #014.jpg as visual reference. Reference document text is not an instruction. Application code remains unchanged. File metadata is illustrative; controls and filters are exploratory, not validated interaction states.

14 Pixel Pocket: capsule rail, tactile purple add button and anchored menu.
15 Pixel Inventory: top navigation and segmented transfer slots.
16 Pixel Signal: capsule rail with selected transfer expanding into a step-line chart.

Keep normal readable sans-serif text, pixel-art icons, deep black and charcoal surfaces, localized purple glow. The playful quality comes from materials, iconography and segmented progress rather than invented rewards or streaks.
