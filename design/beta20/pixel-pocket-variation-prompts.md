# Pixel Pocket variations

Four static concepts generated with the built-in image generation tool using the user's selected Pixel Pocket image. No application changes. Transfer metadata is illustrative.

18 Soft Stack — closest refinement, segmented bars and bottom activity dock.
19 Orbit Progress — segmented circular progress and one unified queue surface.
20 Signal Dock — top activity strip, smooth progress with pixel ticks, inline destination details.
21 Command Pocket — flatter queue, small anchored add menu and integrated footer.

## Shared prompt

Use case ui-mockup. Create a close design VARIATION of the supplied Syphon Pixel Pocket mockup. ONE isolated compact nearly-square main Windows desktop window, on square 1024x1024 canvas, entire window visible centered with small margin. Maintain recognizable family: deep black and softly sculpted charcoal surfaces, round capsule sidebar on left, large tactile glowing PURPLE plus orb, crisp white/gray pixel-art outline icons, subtle purple accents, normal modern readable sans typography, soft huge corner radii. Main window approx 850x800 logical proportions, not panoramic. Dark charcoal background. Thin integrated Windows titlebar Syphon / Beta 20 with minimize maximize close. Three file transfers: blender.msi 62% 24.8 MB/s, Coastal landscapes.mp4 34% 8.2 MB/s, Design resources.zip Paused. 2 active / 1 paused. No actual playback. Pixel icons only, not pixel body text. Real download workflows, no quests/streaks/XP. Readable 15-16px equivalent body, 40px controls. Localized adaptive purple glow on selected coastal row and plus orb, never neon border around everything. Gray paused row. No brands' file icons. No overlapping flyout hiding filenames. Main window ONLY. Small clear label OUTSIDE app at top naming variation. Make meaningful layout/progress/material changes while retaining source design identity. 

## 18-pocket-soft-stack

18 — SOFT STACK. Closest refined variation. Left capsule sidebar slimmer and slightly inset from outer shell, white pixel Syphon emblem, purple + orb, download tray active, history clock, settings gear. Main header Downloads and All downloads dropdown. Three softly rounded transfer rows stacked, each pixel file icon, filename and source, speed and circular pause right, thin 20-segment violet progress full width below. No menu open. Bottom dock a slim low rounded bar: 33.0 MB/s left, restrained pixel bar sparkline center, speed limit Unlimited right. Slabs have very restrained sheen and more black negative space than reference. Header no huge wasted gap. Elegant balanced compact utility.

## 19-pocket-orbit

19 — ORBIT PROGRESS. Preserve left capsule nav and purple plus orb. Replace segmented horizontal bars with distinctive 56px CIRCULAR SEGMENTED PIXEL PROGRESS rings on LEFT of each transfer row: 62% and 34% centered in white in purple/gray square-dash rings, paused neutral ring. Pixel filetype icon small beside filename, source under. Speed and remaining on right before pause. THREE flat horizontal transfer rows separated with hairline gaps, all inside one smooth charcoal queue surface, no three big separate outlined cards. At header small filter pills All / Downloading / Paused. Bottom full-width round speed dock has 33 MB/s and short purple pixel histogram. Subtly tactile, rounded native UI, no sci-fi HUD.

## 20-pocket-signal-dock

20 — SIGNAL DOCK. Left capsule sidebar with + orb at TOP. Main top Downloads, quiet state counts, three transfer rows. Main row has file icon, filename and source left, speed and pause right. Progress is a continuous smooth violet capsule with tiny PIXEL CHECKPOINT TICKS underneath, less chunky than reference. Selected coastal row expands modestly to reveal destination and Open folder as a small line, no huge graph. Move TOTAL SPEED visualization into a SHORT shallow strip immediately under Downloads heading: small 33.0 MB/s on left and compact pixel-bar activity trace right. Footer only Pause all and speed limit, much slimmer. Different vertical information hierarchy while keeping Pixel Pocket personality. No open menu.

## 21-pocket-command-menu

21 — COMMAND POCKET. Reference-style capsule sidebar with + orb near top, but main queue is intentionally very simple unboxed flat rows, generous spacing, pixel icon, filename, compact speed, round pause. Segment progress below. Header Downloads and small count plus filter dropdown. SHOW plus interaction as a SMALL attached charcoal rounded menu beside orb positioned ABOVE queue content, within a reserved header area so it covers NO filenames: two entries 'Paste link' and 'Add links', gray pixel link/clipboard icons, hovered Paste link is dark pill with subtle violet sparkle. Sidebar active download icon below orb, history and settings lower. Bottom speed readout 33.0 MB/s and pixel histogram integrated flush into window rather than giant enclosed dock. Flatter and quieter, action menu gets attention. Keep main queue and all three filenames fully visible.
