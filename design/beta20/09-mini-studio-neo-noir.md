# Mini Studio — Neo-Noir

Static concept generated with the built-in image generation tool. Maintains compact Mini Studio layout with near-black surfaces and purple illumination. Application code is unchanged.

## Adaptive glow proposal

- Selection: one localized purple bloom follows the selected transfer, crossfading over 250–350ms.
- Downloading: brightness responds to smoothed recent transfer activity, within a narrow range; no per-packet flashes or continuous idle pulsing. Brightness does not claim a calibrated speed measurement.
- Paused or idle: illumination settles to a quiet neutral rim over 300ms; status remains explicit in text.
- Focus: only the focused input or hovered control gains a small local edge highlight. Keep text backgrounds opaque and dark.
- Reduced motion: use a static selected glow with immediate state changes. A glow intensity setting can offer Off, Subtle and Standard.

The image demonstrates the selected active state only; adaptive animation is proposed, not implemented. Decorative rim intensity can be tuned after feedback.
